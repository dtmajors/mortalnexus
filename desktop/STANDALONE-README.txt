Mortal Nexus 1.18.0 - Free Community Release

No keys, accounts, or subscriptions are required.
Download and source: https://github.com/dtmajors/mortalnexus
Donate: https://www.paypal.com/donate/?hosted_button_id=677CRL426BE9Q
Discord: https://discord.gg/MmV7gNV5ZG

Run MortalNexusSetup.exe on Windows x64, then open Mortal Nexus.
.NET is included. WebView2 Runtime is required.
Maps and reference data are local. Third-party live calculations need internet.
Hosted accounts, market, messaging, submissions, and shared builds are retired.

Original Mortal Nexus code is MIT licensed. Third-party assets retain their
own rights and credits. Customer and old license records are private and are
not part of this release.
