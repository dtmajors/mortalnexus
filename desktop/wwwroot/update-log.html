Update Log

Mortal Nexus release history. Now free, open source, and supported by players.

Current release 1.18.0 October 11, 2026
Free & open source

Version 1.18.0

October 11, 2026
  • Mortal Nexus is now free for everyone. No license keys, website account, or paid activation service is required.
  • All former Premium tools are unlocked, including crafting, loot, character planning, guides, spells, and macros.
  • Source code and Windows downloads are available on GitHub. The Updates button opens the latest release.
  • Added prominent optional donation links. Donations support development, not access to features.
  • Maps and reference assets are bundled locally. Third-party live calculation services still require internet access.
  • Hosted market, messages, online accounts, submissions, and shared builds are retired.
