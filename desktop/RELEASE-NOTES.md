# Mortal Nexus 1.18.0: Free and Open Source

Mortal Nexus is now free for everyone. No license key, website account,
KeyAuth activation, Railway service, or Discord sign-in is required to open it.

## Support the Project

**[Donate through PayPal](https://www.paypal.com/donate/?hosted_button_id=677CRL426BE9Q)**

If Mortal Nexus saves you time, please help support its continued development.
Donations help make ongoing work on the maps, tools, fixes, and updates possible.
Every contribution is appreciated. All tools remain free whether you donate or not.

## Install

Download **MortalNexusSetup.exe** below and run it on Windows x64. Then open
Mortal Nexus. Existing customers no longer need their previous key.

The .NET runtime is included. Microsoft Edge WebView2 Runtime is required;
if the app reports it missing, install it from
[Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).

## Changes

- Removed the activation screen and all paid feature restrictions.
- Opened the original application source under the MIT license, with separate
  third-party rights and attribution preserved.
- Replaced license settings with About and Support.
- Added prominent optional donation links and GitHub source/download links.
- Bundled map and reference data locally.
- Kept third-party crafting and live character-calculation integrations;
  these still require internet access.
- Retired hosted accounts, market, messages, submissions, and shared builds.
- Changed Updates to open the latest GitHub release.

## Source and Build Assets

The source is in [desktop/](https://github.com/dtmajors/mortalnexus/tree/main/desktop).
**MortalNexusAssets.zip** contains the large assets needed to build from source.
The asset downloader verifies the release archive before extracting it.
**MortalNexus-Netlify-Redirect.zip** is the static website redirect package.

Customer records, old license inventories, private tokens, and admin credentials
are not included in the public source or release files.
